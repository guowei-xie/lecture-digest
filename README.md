# lecture-digest

用**一场已内置的知识型大会**「飞书 AI 绝活大会 / VibeCoding 大赏」 × **你自己的个人知识库**（经验、痛点、在做的项目、已有认知），产出**启发建议**，并做成一份自包含、可交互、能自测的复盘 HTML 页。

核心不是复述大会讲了什么，而是这个交点：**「大会的内容 × 你的处境」**——把大会里的知识点接到你已有的东西上，指出关联、类比、可迁移之处，最后收成一套你能照着做的定制方法论与行动建议。

## 它和普通「讲座复盘工具」有什么不同

大会内容**已经内置、已经备好**：六位讲者的逐字稿已被读懂、清洗（纠正语音转写的同音错别字、过滤口语噪声）、按讲者模块化提炼，固化在 `assets/knowledge-base.md` 里。

所以你**不需要提供任何讲座材料，只需要说说自己的情况**。真正需要用户提供、也是本技能价值所在的，是**用户自己的背景**——那是产出启发建议的另一半原料。

## 内置的六个模块

大会按讲者组织成 6 个模块（外加顶部全局 TL;DR 和结尾 Takeaway）：

1. AI native 组织
2. Level 3 会议演示（一边开会一边干活）
3. 「压铸为真」的六条
4. 看板式 AI 工作流
5. 三线城市工厂的 FDE（AI 改造）
6. 1000 个 Agent 并行开发

## 产物

一个**自包含的单文件交互式 HTML**：

- 大会知识的可视化模块（要点、案例、金句、表格、时间线）
- 每个模块配套互动测验：2–3 道即时判分选择题 + 1 道开放思考题
- 贯穿全程的「💡 启发」标注（大会知识点 × 你的处境）
- 收口的**「为你定制」方法论 + 行动建议**——这才是主角

所有 CSS/JS 内联，不引外部资源，双击即开、随手可分享。

## 怎么触发

只要提到类似「结合我的情况 / 我的项目 / 我的知识库，把这场飞书 AI 绝活大会（VibeCoding 大赏）的东西给我启发、给我建议、落到我身上、做成可视化复盘、考考我」，即使没明说「用 lecture-digest」也会主动触发；也可以直接 `/lecture-digest` 唤起。

**冷启动时它会主动问你的背景**：角色/行业、当前最头疼的痛点、手上在做的项目/产品、已有的知识或工具栈。给了背景，才能把复盘从「大会讲了什么」变成「这对你意味着什么、你该怎么做」。

（不方便说也行——会先出一份通用复盘页，你随时补背景，再叠上「为你定制」那一层。）

```

├── assets/

    └── extract_text.py          # 从 docx/pptx/字幕等提取纯文本（纯标准库，无需 pip）

```

## 适用 / 不适用

**适用**：结合个人背景，把这场内置的飞书 AI 绝活大会做成启发建议 + 可视化复盘 + 自测。

**不适用**：

- 整理**别的、非内置的**讲座材料（本技能知识基础固定为这一场；如需纳入新材料，会临时补做清洗与模块化，见 SKILL.md 附录）
- 给同事看的工作纪要 / 待办派发
- 纯 API / 开发文档

## 设计信念

**忠于内置知识基础，但一切为「落到这个人身上」服务。** 大会侧内容都能追溯到 `knowledge-base.md`（不编造观点、数据、案例）；启发建议必须能追溯到「大会某个知识点 + 用户某个事实」的组合，不做脱离用户处境的通用鸡汤。独特价值就在「这场大会 × 这个人」的交点上。
